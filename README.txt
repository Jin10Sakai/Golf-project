Golf Mania was developed as a part of our CSE 102 sessional project. The game was developed by Rafsan Nafee (2505155) & Mahian Tahsin (2505158). The project was developed in C language using the Raylib library functions. The project was supervised by Sumaiya Sultana Any Ma'am. We hope you enjoy the game!!

How To Play:
  - open Vscode and open the folder Golf Mania there.
  - Before running the game make sure the "raylib.h" & "raymath.h" header files are present in the folder.
  - Also check whether the Assets folder is present and all the required fonts, textures and audios are downloaded or not.
  - Run the Golf Mania. file using the "Run & Debug" Option or simply press f5.
  - The instructions on how to play the game are given inside the game. Read the instructions carefully.
  - Choose either single player or multiplayer & enjoy!
